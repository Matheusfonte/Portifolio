Pet Shop

Aplicação web criada para apresentar produtos, serviços e informações para quem procura cuidados para animais de estimação.

🐾
HTML5 CSS3 JavaScript Design responsivo

Sobre o projeto

O projeto apresenta uma navegação simples e responsiva, permitindo conhecer os principais produtos e serviços oferecidos pelo Pet Shop.

Principais funcionalidades

  • Apresentação de produtos para animais;
  • Divulgação de serviços e cuidados;
  • Organização por categorias;
  • Informações de contato;
  • Layout adaptado para computadores e celulares.
