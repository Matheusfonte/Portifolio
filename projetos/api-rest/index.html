API REST de Gerenciamento

Back-end desenvolvido para praticar organização de rotas, regras de negócio e operações com banco de dados.

{ }
Node.jsExpressMySQLPostman

Sobre o projeto

A API segue uma estrutura simples e separa rotas, controladores e acesso a dados, facilitando a manutenção do código.

Principais funcionalidades

  • Cadastro de novos registros;
  • Listagem e busca de informações;
  • Atualização e exclusão de dados;
  • Validação das informações recebidas;
  • Testes de requisições pelo Postman.
