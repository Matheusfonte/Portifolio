Sistema de Despesas Pessoais

Aplicação criada para ajudar usuários a organizar categorias e acompanhar suas despesas de forma simples.

R$
ReactNode.jsExpressMySQLSequelize

Sobre o projeto

O sistema reúne front-end, back-end e banco de dados. Cada usuário acessa seus próprios registros por meio de autenticação.

Principais funcionalidades

  • Cadastro e login de usuários;
  • Cadastro e organização de categorias;
  • Registro, consulta e controle de despesas;
  • Comunicação com API REST;
  • Dados armazenados em banco MySQL.
